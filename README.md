# Math Graphs

A Java desktop application for displaying CSV data, generating graphs, and calculating basic statistical values using Java Swing and JFreeChart.

The application is designed to:

1. Load precipitation data from `JanMar18.csv`.
2. Display the CSV data in a table-like layout.
3. Generate bar and line charts for precipitation intervals.
4. Calculate and display statistical values from `Pasta1.csv`.
5. Show the results through a tabbed graphical interface.

## Features

- CSV data loading
- Table-style display of CSV values
- Bar chart generation
- Line chart generation
- Mean calculation
- Median calculation
- Mode/statistical frequency analysis
- Variance calculation
- Standard deviation calculation
- Tabbed Swing user interface
- JFreeChart visualizations

## Requirements

- Java Development Kit (JDK) 8 or newer
- An IDE such as Eclipse, IntelliJ IDEA, or NetBeans
- JFreeChart
